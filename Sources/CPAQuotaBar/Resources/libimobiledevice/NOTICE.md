# Bundled mobile-device tools

This directory contains replaceable command-line executables and dynamic
libraries used to read battery data from Finder-paired Apple mobile devices.

- libimobiledevice, libusbmuxd, libplist, and libimobiledevice-glue:
  https://github.com/libimobiledevice
- `comptest` source:
  https://gist.github.com/nikias/ebc6e975dc908f3741af0f789c5b1088
- OpenSSL:
  https://www.openssl.org/source/license.html

See `COPYING` for the bundled LGPL license text and the project-level
`THIRD_PARTY_NOTICES.md` for attribution details.
